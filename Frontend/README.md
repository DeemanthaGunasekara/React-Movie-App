# 🎬 React Movie App - Frontend

Frontend application built with **React 19**, **Vite 8**, and **React Router v7**.

See the root [README.md](../README.md) for full documentation and Docker setup.

---

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Production build
npm run build
```
